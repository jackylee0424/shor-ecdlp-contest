# briefs — task briefs handed to sub-agents

One markdown file per delegated task: `<NN>-<slug>.md`. A brief states the goal, the inputs, what has been
ruled out, the output files, and what "done" means. Launch it with `formal-tools/codex-agent.sh briefs/<file>.md`.
Keep briefs after completion as a record of intent; the outcome goes in work-notes.
