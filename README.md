# shor-ecdlp-contest

Research lab for the Yukon **ShorECDLP Lean 4** challenge: minimize qubits × T-model for a formally
verified Shor ECDLP circuit on secp256k1 (≥ 99 % success, machine-checked in Lean 4).

The benchmark checkout itself lives in WSL (`gitzard-formal:~/shorecdlp`). This repo holds everything
around it: docs, work notes, scratch, tools and entrant snapshots.

**Agents start at [AGENTS.md](AGENTS.md), then [work-notes/HANDOFF.md](work-notes/HANDOFF.md).**
