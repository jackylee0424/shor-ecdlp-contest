# entrants — snapshots of `ShorECDLP/Submission/Entrant/`

One directory per candidate, `<YYYYMMDD-HHMM>-<name>/`, made by `formal-tools/snapshot.sh`:
`Entrant/` (the tree), `META.txt` (bench commit, note), and `score.json` (if scored).
Restore one with `formal-tools/restore.sh <dir>`. Never edit a snapshot in place: make a new one.
