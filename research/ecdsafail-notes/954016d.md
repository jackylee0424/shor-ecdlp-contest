# greedyfrog 849: carry pools, junk parking, measured erasures and mid mask passes — 849 x 4,918,479.342

**Model:** Claude Opus 5.5 (Anthropic), run in Claude Code. The effort setting is not exposed in this session.
**Result (trusted `eval_circuit`, all 9,024 shots OK, 0 classical / 0 phase / 0 ancilla):** 849 qubits x
4,918,479.342 average executed Toffoli, score 849 x 4,918,479 = **4,175,788,671**. This is a low-qubit Pareto point.
It does not beat the scalar leader. It is below the public 849 row (5,076,051).
**Base:** our greedyfrog rows, 825 (`39ef23e2`) and 815 (`ec1e870b`). The traversal (one greedy binary Euclid
digit per uniform slot, decisions re-derived from the cofactors), its windows, its slot count and its failure
budget are unchanged. This row spends 849 qubits on cheaper slots. The benchmark files are unchanged.

## In one paragraph

The 815 row squeezed the inverse slot's scratch onto borrowed passenger lanes. This row goes the other way: the slots
read a qubit cap and take clean ancillas and carry pools wherever the cap leaves room, falling back to borrowed lanes
only below it. With the cap at 849, three further changes take most of the Toffoli:

- **Junk parking.** On early slots the division rows used to run as masked ladders, because the divisor cofactor is
  shorter than the decode window. Now the window's junk lanes are swapped into a zero register once, and all 21 rows
  run as plain pooled ladders.
- **Measured erasures.** Flags that were erased by recomputing them are now X-measured, and their phase repair runs
  in a block conditioned on the outcome. Its Toffoli count only on the shots where the outcome is 1, half of them
  on average.
- **Mid mask passes.** The value and cofactor ladders keep their running mask live between the up and down passes,
  instead of cleaning and rebuilding it with comparators.

## 2. Budget-aware slots and carry pools

`GreedyFrog::cap` is the circuit's peak (`GREEDYFROG_PEAK = 849` in the shell). At every site the slot checks the room
left under it:

- **ANDs, comparators, increments, constant adds:** clean ancillas when there is room, borrowed passenger lanes
  (Barenco et al. Lemma 7.2, as in the 815 row) otherwise. The same code builds an 815-qubit or an 849-qubit
  circuit.
- **Division rows:** logical-AND carries on a clean pool (1 Toffoli per lane, uncomputed by measurement). The pool is
  held only while a rows pass runs. The inverse pass is re-recorded on a pool taken at that time (the same
  function), so r, a1 and the sweep's chain use the lanes in between.
- **Value and cofactor ladders:** the mask ladders' `g` pool over the ordinary lanes outside the window.
- **The 28-lane compare ladders** (top compares, the swap flag's compare, the window compare): a pool, so that
  replaying the up pass inverted uncomputes the carries by measurement.

## 3. Junk parking

After the decode normalises its windows, the X window holds the divisor cofactor tB (MSB at lane 0, LSB at lane
mX - 1), followed by the marker and A's low bits. On slots where some shot has mX < NB + 1, those lanes sit inside
the 28-lane window, so the 825 and 815 rows masked every row that reached them (about 10 Toffoli per lane).

`park_junk` swaps lanes l >= mX of the window into a |0> register, once per slot:

- A running flag turns on at l = mX. A one-hot scan over the complemented 6-bit view of u' = NB - mX finds that
  lane, and the flag is cleared by two comparators afterwards.
- With a zero-padded divisor, a plain non-restoring row computes the same thing the masked row did. The padded lanes
  add 0 (or 2^k - 1 with the subtract flag and carry-in), so rem's lanes below the divisor's LSB come back unchanged
  and the carry passes into the divisor region.
- The rows then run as plain pooled ladders.
- The pass is self-inverse, so the same call swaps the junk back after the inverse rows.
- It relies only on mX >= the slot's window minimum, the same classical bound the masked rows already used, so
  nothing is added to the failure budget.

At 849 every masked-row slot has room to park. The rows section shrank by about 130k Toffoli per division.

## 4. Measured erasures

Where the slot used to erase a flag t = f(state) by computing f again into it, it now does three things:

1. Measures t in the X basis into a fresh bit m (0 Toffoli; t returns to |0> with phase (-1)^(m f)).
2. Opens a block conditioned on m (`push_condition` / `pop_condition`).
3. Inside the block, applies the phase (-1)^f: the same computation with a CZ or Z in place of the final XOR, and its
   own temporaries erased by measurement in turn (nested conditions combine as AND in the simulator).

The grader's average executed Toffoli counts each conditioned gate on the shots where it runs, half of them on
average.

Sites:
- the inverse slot's swap-flag erase and the swap flag's temporaries;
- the swap decode's window compare, `eq` and `lt`;
- the `d` erase (the late top compare);
- the window-slack erase after the normaliser's undo;
- the last-row sweep's per-row one-hot (the sweep is now emitted directly, forward and inverse, instead of recorded);
- the rotation decode's comparators and the sweep's gate initialisation;
- the renormalisation flags in the inverse;
- the step flag at the end of the slot (a two-literal AND, so its repair is a CZ and costs nothing);
- both done-flag erases.

New helpers: `phase_and`, `erase_mbu`, `erase_and`, `ge_erase`, `lt_phase`, and `ge_const_phase` in `mask.rs`.

## 5. Mid mask passes

The value and cofactor passes used `mup` / `mdown`. Those clean the running mask with interval comparators at the end
of the up pass (`f_end`) and rebuild it the same way at the start of the down pass. Between the two passes only the
top carry is read, so the mid variants (`mup_mid` / `mdown_mid`) keep the mask live instead. The down pass hands it
back to its starting value, and both comparator rounds disappear.

## 6. Failure budget and nonce

The decode, the windows and the slot count are those of the 825 and 815 rows. The model rate is about 6.3 expected
failing shots per 9,024, under the PR 419 cap of 18. Every change here is exact on the shots the windows admit.

The tail nonce was scanned again on this gate list (`greedyfrog_nonce_scan`: classical replay of every shot's two
divisions through a bit-exact emulation of the windowed walk and decode). Counting up from 1, 89 is the first clean
value of 115, and `TAIL_NONCE = 89` is committed. The trusted evaluator confirms it. A passing packet does not lower
the true rate; the model rate above is that rate.
