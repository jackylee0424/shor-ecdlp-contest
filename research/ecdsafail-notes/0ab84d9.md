# Clean-workspace multi-control synthesis on the 660-qubit baseline

This candidate derives from bulengerk submission 9a8bbcae-2438-45a2-bb0a-e58e42796186, commit de464c2127fa950522637d5abea1c9ec972dabf6. All original source credits and notices remain. We do not claim the inherited point-addition algorithm, Euclidean traversal, normalization, public envelopes, schedule, or prior gate optimizations as our contribution.

## Substantive change

Reserve twelve dedicated zero-initialized qubits immediately after allocating and declaring the 512 input qubits. Hold these physical owners through every traversal and captured-tape replay. Use them for exact unitary V-chain synthesis of multi-controlled X operations with 3 through 14 controls, only at mc_xor call sites with no existing clean temporary workspace. The existing dirty implementation and calls with retained clean prefixes are unchanged.

For k controls, the replacement computes k-2 prefix conjunctions, performs one final Toffoli, and reverses all k-2 prefix gates. Its cost is 2k-3 CCX versus the no-clean dirty path's 4k-8, a local saving of 2k-5. Negative controls retain the existing X conjugation. No phase approximation or measurement-based cleanup is introduced by this change. All new scratch returns to zero after each complete primitive and remains disjoint from arithmetic controls and targets. The bank is not inserted into mcx_dirty itself, avoiding recursive reuse while controlled replay acts on a partially computed recorded chain.

The source allocation target is 672 qubits, not a measured result. Twelve extra wires trade some width for cheaper controls rather than repeating our failed 659-qubit experiment's expensive owner elimination. The parent arithmetic, schedule, precision, nonce and nonce-control values are unchanged. There is no nonce search or test-dependent tuning. Only src/point_add changes; protected harness, dependencies, toolchain and validity gates remain unchanged.

## Research context

The lineage review of successive low-width submissions showed that width reductions often increased gate cost and that additional scratch or exact control rewrites can recover performance. Relevant modern context is Khattar and Gidney, “Rise of conditionally clean ancillae for optimizing quantum circuits,” Quantum 9, 1752 (2025), https://quantum-journal.org/papers/q-2025-05-21-1752/ and https://arxiv.org/abs/2407.17966 . Qiskit's official MCX synthesis implementation was inspected: https://github.com/Qiskit/qiskit/blob/main/qiskit/synthesis/multi_controlled/mcx_synthesis.py . This submission uses the simpler conventional many-clean-ancilla exact CCX ladder, not a claimed implementation of their one-clean construction or copied relative-phase decomposition.

Independent authored small-component Boolean models checked the primitive, negative controls, scratch restoration, forward/inverse composition and externally controlled replay. One primitive model passed 196,560 cases. An independent composition model passed 296,576 cases including every control value for k=3..14 and controlled-composition cases with arbitrary dirty helpers. These component checks do not execute the entire inherited point-addition circuit and are not full correctness validation.

The full local benchmark is unavailable because the unchanged bubblewrap confinement cannot create its NETLINK_ROUTE socket in the current environment. Official trusted evaluation must establish all 9024 correctness cases, phase cleanliness, ancilla restoration and the actual resource counts. ## Reproduction and implementation surface

Start from the exact cited parent commit. The three edited files are:

- builder.rs: add an empty-by-default owned bank and two source-lowering diagnostic counters. Builder constructors initialize these fields without allocating quantum inputs or changing register declarations.
- pointadd_frogdrop.rs: allocate twelve ancillas after X/Y input declarations, retain their ownership while ordinary temporaries are allocated and released, and free the bank only after all arithmetic and tape replay complete. The existing positional nonce identity remains after that release. Print the count of eligible source lowerings and their local pre-replay cost difference once at completion.
- mask.rs: after the existing negative-literal conjugation, use the dedicated clean ladder only if the filtered existing temporary list is empty and its capacity covers k-2. Assert that neither controls nor target overlap the bank. The existing lowering handles all other cases unchanged.

Build with the repository's pinned Rust toolchain and locked dependencies:

    RUSTFLAGS='-C linker=/usr/bin/gcc' cargo build --release --locked --offline --jobs 2 --bin build_circuit

The final release compilation completed successfully. The unchanged repository benchmark command is:

Locally, a harmless /bin/true probe using the standard confinement flags reproduced the namespace restriction, so we did not execute the generator outside that confinement. ## Diagnostics and comparison rules

The source diagnostic begins CLEAN_MCX_SOURCE_LOWERINGS. Its calls and local_raw_ccx_savings fields count source-level replacements and the sum of 2k-5 over those replacements. They do not account for how frequently recordings are replayed, inverse or controlled lowering, or cancellation. They must not be reported as the final emitted or mean-executed Toffoli saving.

For a useful comparison, separately report maximum emitted qubit ID, generated operation count, generated Toffoli count, average executed Toffolis from the trusted score, correctness status, phase/ancilla status and end-to-end elapsed time. The original baseline's generated and executed counts are different. A smaller per-primitive cost does not prove the final optimized stream is smaller because changing decomposition can change cross-gate cancellation.

Earlier work on eliminating the fourth scalar generated a 659-qubit circuit but exceeded one billion emitted Toffolis and did not finish official correctness validation within its run. That source is not reused here. The present candidate restores the exact cited four-scalar baseline and changes the isolated control-synthesis tradeoff instead. We will classify a failed run by compilation, generation, correctness, phase, ancilla restoration or runtime before selecting a further change. A generated qubit count alone is not success.
