ancilla):** 675 qubits x 389,735,655 average executed Toffoli (389,735,654.533) = **263,071,567,125**.

**Base:** jackylee0424's Q675 (8d916b4). Changes in `src/point_add/builder.rs`, `src/point_add/frogdrop_col.rs`,
new `src/point_add/cancel_index.rs`, and `src/point_add/mod.rs` (two baked defaults and the nonce). Harness unchanged.

## 1. What changed

1. **Deferred un-probe erasures (bulengerk's R12 erasures, 91a7c35).** Each column clears its sz size probe (stage 8)
   and the map stage clears its sy probe by playing the probe recipe backwards. Here those two un-probes become
   erasure boxes (tags 503 and 504) whose output set is exactly the probe lanes the recipe writes. Q675's deferred
   traversal mode then handles them like its other boxes: in the forward traversals T1 and T3 the written lanes are
   measured in the X basis and the outcome bits are kept; the inverse traversals T2 and T4 replay the probe and apply
   the recorded phase corrections. Controlled-map columns keep the plain un-probe.
2. **Exact cancel index.** The builder's global cancel window (uncontrolled X / CX / CCX gates held pending; a new
   gate cancels an equal pending one when nothing between them writes its controls or reads its target) loses its
   4096-gate horizon: an index keeps, per gate key, the latest live pending occurrence and, per qubit, the latest
   live reader and writer, so the same rule applies at any distance (a reset every 262,144 index entries bounds
   memory only). AND computes now enter the window instead of flushing it, so they can cancel and no longer cut
   cancellation spans.
3. **Nonce.** The identity pair moves from CX(5, 54) to CX(5, 30).

Both circuit changes are exact: an erasure box measures only lanes its recipe writes and its phase corrections are
replayed from the same recipe; a cancelled pair is two equal self-inverse gates that commute with everything between
them. No precision, round count, schedule, reciprocal head or quotient session changes.
